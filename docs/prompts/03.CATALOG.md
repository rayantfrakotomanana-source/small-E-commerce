# Task 03: Catalog
## Role
Frontend engineer + product management tool builder.

## Customer pages
1. / Home: logo header, FR/MG switch, search, sections Tech and Divers, menu-style grid (photo, name, price in Ar). Sold-out items greyed with "Épuisé".
2. /produit/[id]: gallery, full description, price, availability, warranty, quantity, "Ajouter au panier".
3. *"Commander sur WhatsApp"* button on each product: opens wa.me/<settings.whatsapp_number> with a pre-filled message (product name, price, link). This lets the store go live on Facebook before checkout exists.
4. Cart: localStorage, drawer, quantity edit, subtotal. (Checkout comes in Task 06.)

## Admin pages /admin/produits
1. List with search and category filter.
2. Create/edit form (FR + MG), price, stock, warranty, multi-image upload to Supabase Storage with client-side compression (max 1200px, under 150 KB).
3. Quick actions for mum: toggle "épuisé", inline edit price and stock.
4. *Delete = soft delete* (deleted_at), with a "Corbeille" view and Restore. Hard delete only for superadmin and only if never ordered.
5. Available stock shown as stock - reserved.

## Done when
Rayan creates a product with 3 photos, it shows on Home in the right category, the WhatsApp button opens a correct pre-filled chat, and mum marks it sold out in 2 taps.
